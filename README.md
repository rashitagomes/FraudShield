# FraudShield — India-focused Streamlit demo

FraudShield is an educational credit-card transaction fraud-screening prototype. The interface uses Streamlit and a trained scikit-learn pipeline.

## Features
- Dark-mode interface, with no sidebar or model-review page
- India-first defaults, with monetary fields displayed as ₹ INR
- Merchant country selection for India and international merchants
- Distance-from-home input in kilometres, with an N/A option for unavailable values
- Estimated fraud score, risk flag, and recent checks for the current session
- Training and evaluation kept separate from the UI

## Setup (Windows PowerShell)
Open this folder in VS Code and run these commands in the project-root terminal:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python train_model.py
python -m streamlit run app.py
```

Streamlit prints a local URL, usually `http://localhost:8501`. Open it in your browser.

## Currency and data caveat
The UI is India-focused and labels monetary fields in INR. The supplied dataset includes multiple merchant countries, but its values should **not** be assumed to be currency-normalized INR without checking its documentation. For meaningful real-world use, normalize transaction amounts to one currency using the exchange rate at transaction time, then retrain. The ₹ labels are a UI convention for this educational demo, not proof that source data values represent rupees.

The distance N/A option sends a missing value to the model pipeline; the trained imputer fills it using a statistic learned during training.

## Important
- `models/fraud_model.joblib` is generated by training and is not included in the ZIP.
- This is an educational prototype, not a real banking decision system. Real deployment requires validation, threshold tuning for class imbalance, privacy/security controls, monitoring, and human review.
